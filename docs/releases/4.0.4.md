# DPI Killer 4.0.4

- Fixed repeated backend recycling and abandoned ciadpi processes occupying successive ports. Stop now waits for the owned process to exit; stale exit/reconnect callbacks cannot revive it.
- A temporary internet outage keeps a healthy backend running. Recovery distinguishes a failing proxy from an unavailable direct connection.
- System-proxy failures now show the same actionable warning in Settings and the menu bar. Failed restoration retains the recovery snapshot.
- Choose Helper or Direct authorization. The signed network helper restores its proxy lease on client disconnect and accepts only the signed application; Direct keeps native macOS prompts.
- Switch ciadpi / SpoofDPI directly in the compact menu, beside the matching blue authorization selector. System Proxy and hotspot optimization are available there too.
- Settings apply automatically, preserve the process when only proxy settings change, and roll back invalid arguments. Presets explain engine-specific effects.
- Logs include backend PID, redacted arguments, exits, proxy transaction errors, connectivity probes, and rollback results.
- Updates preserve an active backend, verify the expected version and signing team, and recover the update UI if shutdown is refused. CI no longer publishes an unsigned replacement for the signed app.

Requires macOS 13+. This package has an Apple Development signature and is not notarized. First launch and helper installation may require native macOS confirmation. Direct mode does not require the helper.
