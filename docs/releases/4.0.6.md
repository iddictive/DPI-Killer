# DPI Killer 4.0.6

- Repeated SpoofDPI outbound TCP timeouts no longer flood Event Logs. The first error appears immediately; further matching failures are counted in a summary every ten seconds, including the latest error.
- Other errors, diagnostics, and backend lifecycle events remain separate. Backend output is read as complete lines, preserving messages split across pipe reads.

This package uses the existing Apple Development signature without notarization.
