# DPI Killer 4.0.8

- Fixes proxy-wide stalls caused by slow DNS lookups. The repaired ciadpi engine is included in the app and replaces an older managed engine on upgrade.
- Keeps working connections open when a remote health-check site fails. The watchdog checks the local proxy instead and still restarts an unresponsive backend.
- Preserves custom executable paths, newer explicitly installed engines and direct access to local networks.

This package uses the existing Apple Development signature without notarization.
