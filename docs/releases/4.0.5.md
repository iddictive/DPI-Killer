# DPI Killer 4.0.5

- SpoofDPI's System DNS mode now uses the native macOS resolver, including its network-specific DNS configuration and cache. This avoids the separate Go resolver path that returned DNS failures as HTTP 502 / CFNetwork 310.
- Backend errors remain available in Event Logs when the log window is closed; opening the window still enables verbose output.
- Connectivity Diagnostics logs its actual engine, proxy route, port, HTTP response, native error code, and elapsed time.

The proxy modes and bypass presets are unchanged. This package uses the existing Apple Development signature without notarization.
